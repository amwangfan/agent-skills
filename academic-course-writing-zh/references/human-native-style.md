# Human-native academic style

本文件用于校准“人类原生专业写作”的抽象特征，不提供可复制的某位作者文风。

## 1. 什么是真正值得学习的“人味”

专业作者的自然感通常来自：

- 知道哪些背景可以省略；
- 知道什么细节必须写；
- 对证据强弱有判断；
- 会在重要处展开、次要处压缩；
- 不为每个技术对象分配相同篇幅；
- 在需要时直接下判断；
- 不把所有信息都包装成“意义”；
- 术语使用稳定；
- 句法跟着逻辑变化，而不是跟着模板变化。

因此，不使用“随机改写”作为人类化策略。

## 2. 从真实作者样本提取 Style Profile

建议提供至少 2–5 段由作者本人独立完成的旧作。
理想长度约 800–3000 个中文字；更多也可以。

提取：

### 句子
- 常见句长；
- 长句出现位置；
- 是否大量使用分号/括号；
- 是否偏好直接主谓句；
- 是否常用无主句；
- 是否常以条件句开头。

### 段落
- 主题判断通常位于段首还是段中；
- 一段通常解释一个机制还是多个相关事实；
- 段末是否总结；
- 段落长度变化是否明显。

### 论证
- 是先给结论再解释，还是先列事实再判断；
- 常见的因果连接方式；
- 如何表达不确定性；
- 如何指出限制；
- 如何比较两种技术方案。

### 术语
- 中文术语和英文缩写如何首次出现；
- 是否保留英文；
- 是否习惯使用公式符号代替重复文字。

### 作者声音
- 是否常写“本文”；
- 是否接受“我们”；
- 是否倾向克制判断；
- 是否会明确写“更关键的是”“主要限制在于”等作者判断。

## 3. 样本迁移边界

只迁移：
- 节奏；
- 句法倾向；
- 信息组织；
- 判断强弱；
- 标点习惯。

不迁移：
- 独特比喻；
- 可识别长句；
- 特有措辞串；
- 样本中的事实；
- 样本中的引用；
- 样本中的个人经历。

如果样本来自其他作者而不是用户本人，只做一般学术语域分析，不做个人风格复刻。

## 4. 人类文本并不等于“不规范”

不要用：
- 错别字；
- 标点错误；
- 随机重复；
- 口头禅；
- 突兀碎句；

来制造“真人感”。

成熟作者也会修改自己的文章。自然和准确可以同时存在。

## 5. 参考的写作原则

本 Skill 的风格规则吸收以下公开学术写作资源中的一般原则：

- Nature Portfolio：科学写作强调清晰、直接、聚焦，并让技术术语服务于必要表达；
- Nature/Scitable：有效科学写作应清晰、准确、简洁，复杂内容不需要故意写得复杂；
- Purdue OWL：删去不增加含义的赘词，优先明确动作和主体；
- George Mason University Writing Center：学术写作应精确、简洁，先解决整体重复，再处理句子级冗余；
- University of Manchester Academic Phrasebank：学术表达按修辞功能组织，并根据证据使用恰当的谨慎措辞；
- SAE / paper-refine：专业编辑优先保护科学事实、公式、数值和引用，并遵守“无必要不改写”。

这些原则用于形成通用风格约束，不复制任何具体文章。
