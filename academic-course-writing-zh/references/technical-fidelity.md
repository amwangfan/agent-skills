# Technical fidelity

## 永远优先保护

- 专业术语；
- 固定译名；
- 数学符号；
- 公式；
- 变量与下标；
- 单位；
- 数值；
- 图表编号；
- 引文和文献编号；
- 标准编号；
- 型号；
- 工艺节点；
- 测量/仿真条件。

## 编辑风险

### 1. 同义词错误

技术术语不能按普通中文同义词处理。

### 2. 结论强化

原文：
“可能与热应力有关”

不能改成：
“由热应力导致”。

### 3. 范围扩张

原文：
“在 25 ℃、该测试结构下……”

不能删去条件后写成普遍规律。

### 4. 比较失真

不同文献中的参数若测试条件不同，不能只看数值大小直接排序优劣。

### 5. 研究对象漂移

修改长句时检查：
- 谁是主语；
- 哪个变量变化；
- 原因和结果有没有互换；
- 修饰语是否仍然指向原对象。

## 推荐动作

遇到可疑内容时：
- 标记；
- 提问；
- 建议查证；
而不是静默“修复”。
