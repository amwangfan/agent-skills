# Revision checklist

## 第一遍：事实

- [ ] 数值未改变
- [ ] 单位未改变
- [ ] 公式未改变
- [ ] 引用未虚构
- [ ] 专业术语统一
- [ ] 条件没有被删掉
- [ ] 相关性没有被改成因果

## 第二遍：论证

- [ ] 每节有明确问题
- [ ] 关键判断有依据
- [ ] 文献不是简单作者罗列
- [ ] 比较维度一致
- [ ] 限制条件写清
- [ ] 结论不超过证据

## 第三遍：课程论文身份

- [ ] 没有虚构原创研究
- [ ] 没有虚构实验结果
- [ ] “本文提出”确有提出内容才使用
- [ ] “结果表明”有真实结果才使用

## 第四遍：自然度

- [ ] 没有无信息量宏大开头
- [ ] 没有连续模板段落
- [ ] 不强凑三点
- [ ] 连接词不过量
- [ ] 不每段强行总结
- [ ] 段落长度服从内容
- [ ] 句子长短服从逻辑

## 第五遍：作者样本

- [ ] 样本存在时已先做 Style Profile
- [ ] 没有复制样本原句
- [ ] 保留作者常见节奏
- [ ] 避免作者明显不用的套话

## 第六遍：最小修改

- [ ] 原本清楚的句子没有为了“去 AI”被改坏
- [ ] 没有随机换同义词
- [ ] 没有故意加错误
